# AI usage

This project used AI coding assistants (Codex, and OpenCode) under human direction for drafting code, tests, and documentation.

AI-generated output is not accepted as runtime evidence. All implementation must be reviewed, validated, and approved by the project team before use in production decisions, metrics, datasets, or published results.

AI assistance was limited to code scaffolding, static checks, and documentation support. Final analytics, ML outputs, forecasts, recommendations, and operational evidence must come from the repository's own implemented pipelines and verified execution artifacts.
